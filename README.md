# Creator POS

簡易同人場 POS 系統。  
A simple POS system designed for artist alley / convention booths.

---

## 功能 Features

- 商品銷售 Product sales
- 庫存管理 Inventory management
- 福袋模式 Lucky bag mode
- 特殊套組優惠 Special bundle pricing
- CSV 匯出 CSV export
- localStorage 儲存 Local browser storage
