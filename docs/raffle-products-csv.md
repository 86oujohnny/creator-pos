## 摸彩

開始編輯摸彩後，點選商品記錄這一抽帶走的獎品；完成後加入一抽。每抽 250 元、每三抽 600 元，與福袋及一般商品分開計價。內容的零售價格不加入摸彩費用。沿用福袋的抵用券排除方式。

每一抽可按「編輯摸彩」修改工作副本，取消保留原內容。已付款的摸彩先從銷售紀錄進入訂單編輯，確認結帳才替換原訂單。獎品在結帳時扣庫存；缺貨阻擋結帳，改單、退貨與撤銷沿用原有單一狀態提交及失敗回復機制。內容編輯尚未完成時不能結帳。

## CSV

使用者回報綠色按鈕點擊無反應。原先被 fieldset 禁用的按鈕仍顯示綠色，現增加禁用視覺狀態；未取得寫入權時仍需依頁面提示取得寫入權，不繞過資料載入保護。

下載移除 `_blank`，不再於一秒後銷毀 Blob URL；改保留可再次點擊的下載連結，直到下次匯出才釋放前一個 URL。建立失敗會顯示錯誤，無已結帳訂單時顯示原因，不修改訂單資料。CSV 保留 BOM、歷史成交金額，新增摸彩及內容標籤並展開巢狀套組庫存成員。

審查修正：每筆訂單新增一列「訂單合計」，只有此列的「該筆總額」計入有效淨營收，品項及內容列不重複填入總額。改單與退貨的舊紀錄仍匯出並標記狀態，其有效總額、銷售數量與出庫數量為零；「原成交總額」保留當時金額供稽核，不用於淨營收加總。銷售數量只計有效訂單的頂層銷售品項（每抽算一項），出庫數量只計實際庫存葉節點，避免摸彩／套組與其內容重複計數。沿用現有撤銷流程：撤銷的紀錄已從銷售紀錄移除，不另建交易歷程。

CSV 欄位增加「訂單狀態、銷售數量、出庫數量、原成交總額」，銷售編號改用穩定訂單 ID，改單關聯顯示於訂單合計的內容來源欄。外部試算表若依賴舊欄位或以每列計一件的方式統計，需要調整；淨營收加總「該筆總額」，有效銷售與實際出庫分別加總對應數量欄。CSV 採 UTF-8 BOM 與 CRLF，文字內逗號、引號及換行保持標準引用跳脫。

瀏覽器自動化驗證實際下載事件與檔案內容，不等同 iPad Safari 實機驗證；尚不能確認使用者當時無反應的唯一原因。

## 驗證與部署

`npm test` 執行原有價格／庫存遷移與儲存安全測試，以及新增摸彩、編輯、退貨、故障重試、CSV 測試。`npm run test:browser` 以隔離本機 origin 和虛擬資料執行，不讀寫正式資料。

審查後結果：37 項單元測試通過；Chromium 瀏覽器檢查涵蓋 61 張圖片逐張解碼、摸彩計價、編輯與取消、儲存失敗重試及重載後庫存、CSV 實際下載與再次下載、Blob URL 釋放、下載建立失敗提示、雙分頁鎖定與交接，以及不支援 Web Locks 時禁止寫入。單元測試另涵蓋 1～7 抽明確預期值、0～20 抽獨立計價驗證、零售與獎品共用庫存、改單／退貨失敗後回復、舊資料相容性、無效庫存與已刪除自訂獎品的歷史快照。1024×768、390×844 截圖已檢視，手機寬度無橫向溢位。環境未安裝可執行的 Playwright WebKit，未執行 WebKit 或 iPad Safari 實測。
